# Salon Lead Machine

A standalone product build for a conversion-focused salon website and lead management system.

## Current MVP

- Salon landing/demo website
- Services and offers
- Lead capture form
- Local lead pipeline
- Lead status updates
- Salon setup screen
- Mobile-first responsive UI
- No dependency on the existing STall Store Automation repository

## Product direction

This repository will evolve into a reusable salon sales system that can be sold to salons as a website + lead automation product.

Planned next layers:

1. Supabase authentication
2. Multi-salon workspace/data model
3. Persistent leads and customer records
4. WhatsApp enquiry/follow-up integration
5. Owner dashboard
6. Appointment workflow
7. Offer management
8. Google review workflow
9. Deployment template for each salon
10. Subscription/payment layer
